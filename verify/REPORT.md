# End-to-end verification report

Generated by `verify/e2e.py` (`make e2e`). Reference: [dbt-labs/jaffle-shop@5beb145](https://github.com/dbt-labs/jaffle-shop/tree/5beb145b00f5465ec759cfcdd9745e858818cf95) on DuckDB.

Two runs:

1. **Original export**: what PowerCenter would produce. Differences from jaffle-shop are expected where the mapping has a defect; each one is listed with its cause.
2. **Repaired export**: the same export with the diagnosed defects patched (`verify/repair_mapping.py`). If the diagnosis and the converter are right, this matches jaffle-shop on every shared column.

Patches applied for run 2:

- **P1** Crossed target links: X.A -> T.B while X.B -> T.A (STG_ORDERS cents/dollars, STG_PRODUCTS price, CUSTOMER_360 lifetime money, PRODUCT_DAILY_PERFORMANCE margin/flag). Relink each port to the target column of the same name.
- **P2** STG_ORDERS.SUBTOTAL / TAX_PAID are number(15,0) but hold dollars: widen to number(12,2) in the target and source definitions and in the Source Qualifier ports that read them.
- **P3** Variable-port order: v_PREV_* copies the current row's key ABOVE the variable that compares against it, so the comparison is always true. Move each such variable below its last reader.
- **P4** JNR_ORDERS_ITEMS_AGG makes orders the MASTER of a Master Outer join, which keeps all DETAIL (item summary) rows and drops orders without items; its ORDER_ID output also comes from the item side. Use Detail Outer (keep every order) and output the key from the orders side.
- **P5** EXP_SUPPLIES tests PERISHABLE = 'Y' OR '1', but the data holds True/False: also accept 'TRUE'.
